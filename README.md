# jev-skill-router

> Placeholder. The real README is written separately with the `readme-writer` skill.

A Claude Code `UserPromptSubmit` hook that asks TypeSafe Jev which of your installed
skills fits the prompt, and in its default `shadow` mode logs the answer instead of
speaking it. Operating manual: [`skills/jev-skill-router/SKILL.md`](skills/jev-skill-router/SKILL.md).

The `mode` setting uses a dropdown, which needs Claude Code v2.1.271 or newer; on older
versions set the mode with the `JEV_ROUTER` environment variable instead.
